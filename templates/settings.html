{{ provider_icon('google', 18) }} Set up in Gmail
  1. Open Gmail → Settings → Forwarding and POP/IMAP.
  2. Click Add a forwarding address and paste the address above.
  3. Gmail sends a confirmation code to MailMind. It will appear on this page within a few seconds; refresh if you don't see it.
  4. Enter the code in Gmail, choose Forward a copy of incoming mail and keep Gmail's copy in the Inbox, then Save changes.

Only want some mail? Instead of forwarding everything, create a filter and pick "Forward it to" this address.

{{ provider_icon('microsoft', 18) }} Set up in Outlook
  1. Open Outlook → Settings → Mail → Forwarding.
  2. Turn on Enable forwarding and paste the address above.
  3. Tick Keep a copy of forwarded messages and click Save.

Work account? Your IT admin may need to allow forwarding to outside addresses.
